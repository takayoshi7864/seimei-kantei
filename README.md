# 姓名鑑定

単一HTML（`index.html`）で動く姓名鑑定アプリです。ブラウザで開くだけで使えます（サーバー不要）。

## 構成
- `index.html` … 完成品（辞典データ埋め込み済み）。`python3 tools/build_app.py` で再生成。
- `src/app.src.html` … アプリ本体のソース（`__DICT__` の位置に辞典JSONを埋め込む）。
- `data/dict.json` … 辞典データ（3019件）。
- `tools/` … 辞典データの作成・検証に使ったスクリプト（OCR、列切り出し、字形照合、macOS辞書照合）。

## 辞典データの出どころ
「五行が判る 姓名鑑定字典」（社会運勢学会編）のスキャンPDFを、macOS の文字認識（Vision）で表の列ごとに読み取り、
字形照合（ヒラギノ明朝のテンプレート）と macOS の辞書での読み照合で補正しました。誤読の可能性が残るため、
各字に辞典のページ番号を付けています。疑わしい字（32件）には「要確認」を付けています。

## 判定のしくみ（レポート「体系的姓名鑑定の完全解説マニュアル」に基づく）
- 手順1：格の算出（天格・人格・地格・総格・天数・地数・定数）と五行・陰陽
- 手順2：三大原則（音・形・意味）
- 手順3：五大真理（読み下し30%・五行20%・陰陽20%・天地天底20%・画数10%）

## 画数の深義
鑑定ハンドブック p.111〜126（1〜81画の総論と人生の概観）を `data/kakusu.json` に転記しました
（作成: `tools/make_kakusu.py`）。区分（大吉・吉・中・凶・大凶）は、本文に「大吉数」「凶数」「吉凶中端」などの語がある数（51件）はその語に、
無い数（30件）は本文の内容から判断しました（データの `ex` が 0 のもの）。
Googleドキュメントにある「正名のとき／凶名のとき」の二面作用は、記載のある21の数に付けてあります。

## 天地・天底の配合
Googleドキュメント「天地・天底の配合」の鑑査基準で判定します（表ではなく、次の規則）。
天地同数（点数＝地数）、天地衝突（点数・地数の元数がともに3・5・9）、天地相同数（天格＝地格）、
天大地小・天小地大（天格と地格が2倍程度（1.8倍以上）離れる、または文字数の上下が極端に偏る：4文字以上の苗字に1文字名前、1文字苗字に3文字以上の名前）、天底同数（点数＝定数。五大真理に凶があるときだけ作動）。
講義では「何画差」という定義は無く、目安は「概ね2倍超」と文字数のバランスとされています。

## 流年
生年（西暦）を入れると、数え年（生まれた年＝1歳）を出し、人格・地格・総格の画数を九曜表の系列（画数を9で割った1〜9）に当てはめて、
その系列の数と9年周期で重なる年（回座年）の前後1年に、その画数の象意が表面化するものとして表示します。

## 九星（本命星・月命星・傾斜・同会・最大吉方・吉方）
生年月日（任意で出生時刻）から、手引きp.17「月命星の決定」と同じ規則で本命星・月命星を出します。節入りは太陽黄経から計算します（誤差は数分程度。境界の前後1時間以内は注意を表示）。
傾斜・同会・最大吉方は手引き「本命・月命一覧表」の規則（全72行と照合済み）、同会（本命＝月命）はp.17「月命の切り換え」に従います。
吉方は年盤・月盤・日盤で、五大凶方・月命殺・定位対冲・破・土用殺・小児殺（数え9歳以下）を除いて出します。日盤の星は万年暦と未照合です。

## 権利について
`data/` と `index.html` に含む辞典・鑑定ハンドブックの内容は、社会運勢学会編「五行が判る 姓名鑑定字典」および講座資料の転記です。
内容の権利は各権利者に帰属します。権利者から求めがあれば、該当部分を削除します。

## 仮名の画数
ひらがな・カタカナとも、カタカナの画数に換算します（ア2・キ3・ラ2・ン2 など）。濁点は+2、半濁点は+1、小書き文字は元の字と同じです。
仮名の五行は、五十音の行で決めます。

## アルファベット
講義レジュメp.17の画数で数えます（A3・B3・C1・D2・E4・F3…。小文字・全角は大文字として数える）。
五行は、レジュメに表が無いため、文字の読み（エー・ビー…）の最初の音の行で決めます。
アラビア数字は、画数を漢数字の鑑定数で数えます（1＝1画、2＝2画、3＝3画、4＝5画、5＝4画、6＝4画、7＝2画、8＝2画、9＝2画、0＝1画）。五行は講義の数理表で決めます（1・6＝水、2・7＝火、3・8＝木、4・9＝金、5・0＝土）。漢字の「一」〜「九」は、辞典の音読みの五行のままです。

## 読みの自動入力
姓名の欄に、日本語入力で漢字を打つと、変換前のかな（読み）を覚えて、読みの欄に自動で入れます。
読みの欄を手で直すと、以後は自動で上書きしません。姓名の欄を空にするか、リセットすると、自動入力に戻ります。貼り付けた漢字には、読みは入りません。

読みの欄は、ひらがなに固定します。カタカナ・半角カナは、ひらがなに直します。読みの欄で日本語入力により漢字に変換した場合は、変換前のかな（読み）に置き換えます。貼り付けた漢字や、アルファベット・数字は、取り除いて、エラーを表示します。
